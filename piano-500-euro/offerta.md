# Offerta: "Etichetta pronta per la stampa in 72 ore"

## Posizionamento (una frase)
> Trasformo l'etichetta del tuo prodotto in un'etichetta che sembra da scaffale di farmacia, pronta per la tipografia, in 72 ore, a prezzo fisso.

## Pacchetti

### BASE — 90 €
- 1 etichetta fronte (1 formato)
- 2 proposte iniziali, 2 revisioni
- File PDF stampa (abbondanze, crocini, CMYK) + AI sorgente
- Consegna 72 h

### STANDARD — 150 € ⭐ (il più venduto)
- Fronte + retro/laterali (INCI, avvertenze, lotto, simboli obbligatori)
- 3 proposte, 3 revisioni
- Check conformità base: simboli PAO, e-mark, riciclo, dimensione minima testi
- PDF stampa + AI + PNG per e-commerce
- Consegna 72 h

### LINEA — 350 €
- Fino a 4 prodotti della stessa linea (sistema coerente)
- Tutto lo STANDARD per ogni etichetta
- Mockup 3D per sito/Instagram
- Consegna 7 giorni

**Extra:** formato aggiuntivo +30 €, urgenza 24 h +50 %, mockup singolo +25 €.

## Garanzia
Se dopo le revisioni non sei soddisfatto, rimborso completo. Nessuna domanda. (Rischio reale quasi nullo, aumenta la conversione.)

## Cosa serve dal cliente (modulo d'ordine)
1. Nome prodotto + brand (logo vettoriale se esiste)
2. Dimensioni etichetta (o foto del contenitore con righello)
3. Testi obbligatori (INCI / ingredienti, quantità, avvertenze)
4. 3 esempi di etichette che ti piacciono
5. Colori / vibe (naturale, clinico, lusso, pop)

## Pagamento
50 % all'ordine, 50 % alla consegna. PayPal / bonifico / Stripe link. Fattura con regime forfettario o prestazione occasionale (sotto 5.000 €/anno).

## FAQ (copia nella landing)
- **Stampate anche?** No, consegno file pronti per qualsiasi tipografia. Posso consigliarne una.
- **E se non so le dimensioni?** Mandami una foto del contenitore: le ricavo io.
- **I testi obbligatori li scrivete voi?** Impagino quelli che mi fornisci e segnalo cosa manca. La responsabilità normativa resta del produttore.
- **Quante revisioni?** Vedi pacchetto. Oltre, 20 € a giro.
